## Projects I've Worked On

### AURA-EMS — Energy Analytics and Forecasting

**Technologies:** Python, XGBoost, LightGBM, Streamlit

I built an energy forecasting platform using an XGBoost/LightGBM ensemble, achieving **9.59% MAPE**. The Streamlit dashboard brings together load forecasts, cost analysis, and estimated CO₂ savings.

What interested me about this project was connecting model performance with practical questions around energy planning, costs, and sustainability.

### Big Data Behind Things You Use Daily — Transaction Fraud Detection

**Technologies:** PySpark, Python, Random Forest, Feature Engineering, Parquet

How can a system identify a suspicious transaction among millions of ordinary ones? That was the question behind this project.

Using the PaySim simulated mobile-money dataset, I built a big data pipeline to process **6.36 million transactions**. The workflow covered data ingestion with PySpark, storage in Parquet format, feature engineering, Random Forest modelling, and suspicious-transaction flagging.

One of the most interesting parts was dealing with the imbalance between legitimate and fraudulent transactions. I compared the model against a simple amount-based baseline and explored why accuracy alone can be misleading when fraud is rare.

On the chronological test split, the model detected all 1,600 fraud-labelled transactions with zero false positives. This result is specific to the simulated dataset and test window; further validation is needed before drawing conclusions about real-world performance.

### Google Play Store App Sentiment Analytics

**Technologies:** Python, Pandas, SQL, Power BI, DAX

App reviews contain more than just ratings. They can reveal what frustrates users and where a product might need attention.

I analysed **40,000+ app reviews**, used Python and SQL to investigate negative-sentiment patterns, and built a Power BI dashboard to communicate the findings and support product recommendations.

This project helped me explore how unstructured user feedback can become useful input for product analysis and decision-making.

### GrowthLens — Product Analytics Dashboard

**Technologies:** Power BI, SQL

A product can attract users without necessarily keeping them engaged. I wanted to explore how data can help make that distinction clearer.

GrowthLens tracks user engagement, retention, funnel drop-offs, and conversion metrics. I used SQL to prepare the data behind the KPIs and Power BI to bring the results together in a dashboard.

### ISEWS — Identity Stress Early Warning System

I developed a Composite Stress Index, applied Isolation Forest for anomaly detection, and presented the patterns through an interactive dashboard.

It gave me an opportunity to work with anomaly detection while thinking about how analytical results can be communicated clearly and responsibly.
